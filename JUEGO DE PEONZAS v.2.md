**Juego Arcade de Lucha de Peonzas en Unity**

Necesito ayuda para crear un juego arcade de combate de peonzas en Unity con las siguientes características:

**CONCEPTO GENERAL:**

* Juego arcade de lucha donde las peonzas combaten en una arena  
* Mecánicas simples, ágiles y fáciles de aprender  
* Estilo arcade: partidas rápidas, controles directos y acción inmediata  
* Multijugador local para 2-4 jugadores simultáneos

**SISTEMA DE PEONZAS MODULARES:**

* Cada peonza consta de partes intercambiables (por ejemplo: base, nucleo, punta de ataque)  
* Cada parte modifica estadísticas específicas:  
  * Velocidad de rotación  
  * Peso/inercia  
  * Potencia de ataque  
  * Resistencia/durabilidad  
  * Velocidad de movimiento  
* Sistema de ensamblaje donde los jugadores pueden personalizar su peonza antes de cada combate

**MECÁNICAS DE JUEGO:**

* Controles simples: movimiento, dash/impulso, y ataque especial  
* Las peonzas pierden velocidad de rotación al recibir golpes  
* Cuando la velocidad llega a cero, la peonza es eliminada  
* Física de colisiones realista entre peonzas  
* Sistema de impulso/boost con cooldown  
* Posibles hazards en la arena (bordes, zonas que afectan estadísticas)

**MULTIJUGADOR LOCAL:**

* Soporte para 2-4 jugadores usando gamepads  
* Sistema de asignación de controles flexible  
* Cámara que encuadre todos los jugadores dinámicamente  
* Modos de juego: todos contra todos, por equipos, último en pie

**ESTRUCTURA DEL PROYECTO:** Por favor, ayúdame a estructurar el proyecto paso a paso:

1. Arquitectura base del proyecto y carpetas  
2. Sistema de física y movimiento de peonzas  
3. Sistema modular de partes y estadísticas  
4. Gestión de multijugador local e inputs  
5. Sistema de combate y colisiones  
6. UI básica (menú de selección de partes, HUD de combate)  
7. Gestión de cámara para multijugador  
8. Sistema de victoria/derrota

**NECESIDADES:**

* Código base en C\# para Unity  
* Explicaciones claras de cada sistema  
* Buenas prácticas de programación orientada a objetos  
* Sistema escalable para añadir más partes y mecánicas después
